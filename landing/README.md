# Landing page · Pente Fino

Landing page da barbearia feita a partir do template **Pente Fino** (Vite + GSAP + Three.js + Lenis).

Publicada em: https://barbearia.eduardotorres-dev.com.br

```bash
cd landing
npm install
npm run dev     # desenvolvimento
npm run build   # gera dist/ (site estático)
```

- Textos, preços, barbeiros e depoimentos estão em `index.html` (dados de exemplo).
- Agenda (gaveta de agendamento): `src/agenda.js`.
- Prompts para regerar as fotos: `receitas/`.
- Cadeira 3D: "Barber Chair", de sweedboy69 (CC BY 4.0) — ver `fonte/cadeira-licenca.txt`.
